# shengyi’s space — Personal Digital Space 2.0

## 1. Brand position

`shengyi’s space` is the living digital identity of an AI Engineer with a software-engineering background. It is not a résumé template and not a project directory. The site should answer five questions in order:

1. Who is shengyi?
2. What kind of systems can he build?
3. How did that capability develop?
4. Which projects prove it?
5. What is he exploring now?

The central narrative is:

> From models to systems. From experiments to useful intelligence.

The résumé is evidence-led. It packages real project practice, technical breadth, system thinking, and current focus without inventing employers, schools, titles, or awards.

## 5. Visual and interaction system

- Preserve the current editorial white-space aesthetic, Mackinac serif display type, Inter UI type, warm black `#191919`, and soft gray `#F4F3F3`.
- Real project screenshots are treated as archival evidence inside clean editorial frames, not as generic cards.
- One restrained cobalt signal color identifies filters, “Now” status, and technical metadata.
- Works uses a filterable Project Atlas: featured cases first, selected systems second.
- Case studies use a repeatable narrative: Context → Challenge → System response → Architecture → Evidence → Outcome.
- Motion remains quiet: page transitions, staggered content entrance, image scale, filter transitions, and subtle arrow movement.
- English and Chinese are first-class modes. Language selection persists locally.

## 6. Extensibility

Projects live in typed data rather than page markup. Adding a project requires one data record and optional visual assets. The same record powers Works, Case Study, Resume, Home highlights, and future Notes links. This keeps the space maintainable as the archive grows.
