# shengyi’s space

A personal digital space for shengyi — AI engineering projects, experiments, notes, and an evolving technical profile.

## Inside the space

- Selected AI engineering case studies
- A wider project archive organized by technical direction
- Personal background and growth timeline
- Open AI experiments and technical notes
- Chinese and English modes

Featured work includes:

- **DriveMind** — multimodal driving decision system
- **MedSynth** — MRI CycleGAN synthesis workflow
- **Slope Sentinel** — satellite risk and emergency command platform
- **Graph Interest** — LightGCN personalization engine
- **VidHarm** — multimodal content-safety system

## Stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, Three.js, React Router, and Lucide React.

## Local development

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## Deployment

The project is ready for Vercel. `vercel.json` preserves direct access to React Router paths such as `/works/drivemind`.
